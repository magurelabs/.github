Magure is an enterprise AI company headquartered in DIFC, Dubai, with delivery centres in India.
We build **MagOneAI**, a platform to build, deploy, orchestrate, monitor and govern AI agents in
production on private cloud, on-premise or air-gapped infrastructure, with any LLM.

## Open source

| Project | What it is |
|---|---|
| [**magoneai-mcp**](https://github.com/magurelabs/magoneai-mcp) | MCP connectors for third-party APIs (Microsoft 365, Google Workspace, Atlassian, databases, web search and more), built on the official MCP Python SDK. Apache-2.0. |

Contributions are welcome. Each project's `CONTRIBUTING.md` explains how to get started, and
every commit is signed off under the [Developer Certificate of Origin](https://developercertificate.org/).

## Security

Please do not open public issues for vulnerabilities. Report them privately through the
**Security** tab of the affected repository ("Report a vulnerability"). Each project's
`SECURITY.md` describes the process.
